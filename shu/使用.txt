专升本高数 · 学习技能树 —— 使用说明
这是什么
这是一个把专升本高数拆成一棵棵「技能树」的学习工具。整本教材被整理成 10 个章节、112 个知识点,每个知识点是一个节点,按照「先学什么、再学什么」的依赖关系连成一张图,让你一眼看清整个高数知识体系的全貌和学习顺序。

核心概念
节点 = 一个知识点(如「两个重要极限」「洛必达法则」)
连线 = 前置依赖(箭头表示「学完 A 才能学 B」)
颜色 = 学习状态:
颜色	状态	含义
灰	未学习	还没开始
琥珀(发光)	学习中	当前正在学
绿	已完成	已经学会
金	已掌握	能熟练运用、融会贯通
层级 = 由浅入深:越靠上的越基础,越往下越深入,严格循序渐进。
怎么用
1. 切换章节
页面右上角的下拉框选择章节,10 章自由切换(函数极限 → 导数 → 中值定理 → 不定积分 → 定积分 → 定积分应用 → 微分方程 → 多元微分 → 二重积分 → 无穷级数)。

2. 查看知识点详情
点击任意节点,右侧(手机上在下方)弹出详情面板,包含:

目标深度:这个知识点该学到什么程度(了解/理解/运用/迁移/掌握)
学习目标:要达到的可检验标准
关键概念:这个知识点的核心术语
通过标准:能做什么题、解决什么问题才算学会
前置节点:学这个之前要先掌握什么
3. 标记学习进度
两种方式,任选其一:

点开节点后,在详情面板顶部点「未学习 / 学习中 / 完成 / 掌握」四个按钮
右键节点,弹出快捷菜单直接选状态
标记「完成」时,它会自动把前置知识点也标成完成(前面的都会了,后面的才算会)。标记「学习中」时,同章节其它「学习中」会自动归零(一次只专注一个知识点)。

进度会自动保存在浏览器里,关掉再打开也不会丢。

4. 看整体进度
页面底部的进度条实时显示:总进度百分比 + 完成 / 掌握 / 学习中 / 未学习 的数量。

5. 浏览操作
拖拽空白处平移画布(手机直接手指拖动)
滚轮 / 双指缩放
右下角 + / − 按钮缩放,⤢ 按钮一键适应屏幕
手机端
手机打开自动适配:详情面板移到屏幕下方、图例精简、画布自适应,直接用手指导航即可。

一句话总结:右上角选章节 → 点节点看「学什么、学到哪」→ 右键或点按钮标记进度 → 底部看整体进度,把整本高数一步步点亮。
