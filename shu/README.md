# 专升本高数 · 学习技能树

把专升本高数教材拆成 10 章、112 个知识点,每章一棵由浅入深的技能树,覆盖整个高数知识体系。

## 快速开始

零依赖,无需 npm install,Node(>=18)启动:

    node server.js
    # 或
    npm start

浏览器打开 http://localhost:3000/

## 章节(右上角下拉切换)

1. 函数、极限与连续(18 节点)
2. 导数与微分(14 节点)
3. 微分中值定理与导数的应用(16 节点)
4. 不定积分(10 节点)
5. 定积分(10 节点)
6. 定积分的应用(8 节点)
7. 微分方程(10 节点)
8. 多元函数微分学(10 节点)
9. 二重积分(7 节点)
10. 无穷级数(9 节点)

## 功能

- 右上角下拉切换章节
- 节点由浅入深(拓扑分层),四色状态(未学习/学习中/完成/掌握)
- 点节点看详情:目标深度、学习目标、关键概念、通过标准、前置节点
- 右键节点或点详情面板按钮切换学习状态,标「完成」自动联动前置节点
- 学习进度存 localStorage,刷新保留
- 手机端适配(窄屏详情面板转底部,画布自适应)
