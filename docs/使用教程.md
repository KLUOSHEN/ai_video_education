## 一、启动与访问

### 1.1 启动服务

```powershell
cd C:\Users\ASUS\Desktop\前端\网页.html
npm start        # 默认 http://localhost:3000（开发热重载用 npm run dev）
```

- 零依赖，**无需 npm install**；Node ≥ 20 即可
- 未配置任何 API Key 时也能体验全流程（用静音音频 + SVG 封面代替真实 AI 生成）

### 1.2 页面导航图

| 页面 | 地址 | 作用 |
|---|---|---|
| 搜索首页 | `/search.html` | 输入知识点 → AI 生成教学视频 |

## 二、搜索首页（search.html）

### 2.1 搜索知识点

1. 在**中间的聊天式搜索卡**输入知识点（如「快速排序」「TCP 三次握手」）
2. 按 **Enter 发送**（Shift+Enter 换行）；也可点击「进入课堂」按钮
3. 支持**上传文件**（.pdf/.doc/.txt/.md/.c/.cpp/.py/.java）和**拍照上传**（📎 和 🖼 图标）
4. 等待生成（进度浮层）→ 自动跳转 `/watch.html` 播放页

**快捷入口：**
- 4 张**快捷知识点卡**：快排、TCP 握手、进程线程、二叉树遍历（点击弹出简介，确认后直接生成）
- **三行滚动推荐**：题目 + 知识点 chip 无限滚动，点击自动填入搜索框

### 2.2 历史记录

- 左侧面板显示所有搜索历史，**点击记录**：有任务 ID 直接打开已生成视频；旧记录自动查服务端兼容
- 「新建搜索」清空当前输入；底部「清除全部历史」可一键清空

### 2.3 个性化配置（提升 AI 讲解针对性）

| 抽屉 | 入口 | 内容 |
|---|---|---|
| 自我介绍 | 搜索卡左上「嗨，同学」 | 昵称、年级、已掌握、目标、性格标签 |
| 课堂配置 | 搜索卡右上「准备好一起学习了吗？」 | 音色选择、课堂角色（**好奇宝宝 / 面试官 / 小白同学**）、是否深度交互 |

保存后以 persona 参数随搜索提交，AI 会按你的人设讲解。

### 2.4 AI 解题助手（右下角悬浮球）

- 点击悬浮球展开聊天面板：提问 → SSE 流式回复
- 回复支持 **Markdown + KaTeX 公式 + 代码高亮**；长回复自动生成**右侧目录导航**（scrollspy）
- 面板可**拖拽移动、四角缩放**，位置尺寸自动记忆
- 快捷操作：清空对话、继续追问（带上下文的「继续」）

### 2.5 错题本 / 学情诊断（本页入口）

侧栏「错题本」「学情诊断」与播放页功能一致，详见 3.5、3.6 节。

## 三、播放学习页（watch.html）

### 3.1 视频播放器

| 操作 | 方法 |
|---|---|
| 播放 / 暂停 | 点击画面或 ▶ 按钮 |
| 快退 / 快进 10 秒 | ⏪ / ⏩ 按钮 |
| 进度跳转 | 直接拖拽进度条（也支持点击定位） |
| 音量 | 音量按钮静音/恢复 |
| 字幕 | CC 按钮开关（深色字幕条，切换时淡入淡出） |
| 全屏 | ⛶ 按钮 |

### 3.2 场景导航

- 右侧**场景列表**按时间排列，点击任意场景即跳到对应讲解位置，当前场景高亮

### 3.3 知识测评（核心学习闭环）

1. 页面内「知识测评」区自动生成 **3 道题**（选择 / 判断 / 填空）
2. 作答后立即判分：显示正确（绿）/ 错误（红）+ **详细解析**
3. **举一反三按钮**：基于当前题生成 2 道变式题追加到末尾，加深理解
4. 答错的题自动进入错题本

### 3.4 导出学习笔记

- **导出笔记（Markdown）**：下载 `.md` 格式课堂笔记（含讲稿与结构）
- **打印 / PDF**：新窗口渲染（KaTeX + mdrender），浏览器打印即可另存 PDF

### 3.5 错题本

- 显示历史错题：题目、你的答案、正确答案、解析
- **错题归因**：点击请求 AI 分析错误原因（概念不清 / 粗心 / 计算 / 阅读等）
- **错题重做**：输入框重新作答，提交后标记复习状态（复习通过 / 待巩固）
- **筛选**：「未复习 / 全部」；未复习错题带**琥珀色标记**
- 后端按 clientId 校验，只能看到自己的错题

### 3.6 学情诊断

| 模块 | 内容 |
|---|---|
| 数据概览 | 总答题数、正确率、连续正确天数、错题数、薄弱知识点数、平均用时 |
| 知识点雷达 | 各知识点正确率可视化 |
| 薄弱项分析 | AI 根据错题给出薄弱点与建议 |
| 趋势图 | 最近 7 天答题正确率柱状趋势 |
| 导出报告 | 一键导出 Markdown 诊断报告 |

### 3.7 AI 解题助手

同搜索首页（悬浮球 → 聊天面板），可针对当前课程内容提问、要练习题、总结考点。

## 五、数据存储与常见问题

### 5.1 数据都存在哪？

| 数据 | 位置 |
|---|---|
| 搜索历史、自我介绍、课堂配置 | 浏览器 localStorage（`historySearch` 等键） |
| 答题记录、错题、诊断 | 服务端 `data/store.json`（按 clientId 隔离） |
| AI 生成的音频/海报 | 服务端 `storage/` 目录 |

### 5.2 常见问题

- **端口被占用**：`node server.js` 报 EADDRINUSE 时，说明已有实例在跑，直接用；或换端口启动
- **没有 API Key**：开发模式自动降级（静音音频 + SVG 封面），配置见 `.env.example`（Qwen 必配、ARK 豆包建议配）
- **视频生成慢**：生成依赖大模型 + TTS，请耐心等待轮询完成，不要重复提交
- **错题看不到**：错题按 clientId 归属，换浏览器/清数据后看不到是正常的

## 六、推荐学习路径

1. **规划**：打开职业技能树，点亮目标职业的技能点，明确方向
2. **提问**：回搜索首页，填写自我介绍与课堂角色，搜索知识点
3. **学习**：在播放页看视频 + 跟字幕 + 做 3 道测评题，错题进错题本
4. **巩固**：错题本重做 + AI 归因；学情诊断查看薄弱点；举一反三变式题
