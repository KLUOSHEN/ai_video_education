 【2026-08-17】技能树节点详情面板 + 论坛体验优化
════════════════════════════════════════════════════════

【本次更新内容】

一、技能树新增可交互「节点详情面板」（参考 MapFlow）
------------------------------------------------
1. 数据模型对齐 MapFlow SkillNode 结构：
   分类 / 难度 / 预计时长 / 推荐深度 / 目标深度理由 /
   学习目标 / 关键概念 / 通过标准 / 前置技能 / 适合方向
2. 16 个核心技能手写完整详情（前端/后端/AI/算法/网络/
   数据等），其余 60+ 技能由 defaultDetail 自动生成兜底
   内容，保证每个节点均有完整面板
3. 面板交互：
   - 点击技能节点 → 弹出技能详情（分类/推荐深度/难度
     星级/预计时长 + 目标深度/学习目标/关键概念/通过标准）
   - 点击职业节点 → 弹出方向概览（技能点数/已点亮/
     覆盖率 + 该方向技能列表，已点亮高亮）
   - 详情内「前置技能」chip 可点击跳转，形成学习链路
   - 「适合方向」chip 可点击聚焦对应职业
   - 右上角 × 关闭面板，点「重置」自动收起

二、论坛体验优化
------------------------------------------------
1. 模块筛选栏 / 最新·热门排序栏在小页面溢出时显示
   可拖动的细滚动条（原为隐藏滚动条，内容展示不全
   也拖不动）
2. 论坛三栏布局改为通栏：左导航贴页面最左边、右栏贴
   最右边，中间内容最大 920px 居中放大

【涉及文件】
------------------------------------------------
- skill/index.html   新增节点详情面板 + MapFlow 风格数据
                     模型（SKILL_DETAILS / 兜底生成器）
- forum/forum.css    筛选栏/排序栏可拖动滚动条、
                     三栏布局通栏调整

【测试方法】
------------------------------------------------
1. 启动：node server.js
2. 打开 http://localhost:3000/skill/index.html
   点击任意技能/职业节点，验证详情面板弹出、前置技能
   跳转、关闭按钮、重置收起
3. 打开 http://localhost:3000/forum/index.html#/all
   缩小窗口，验证模块筛选栏出现可拖动滚动条、
   左右导航贴边、中间内容放大

【验证结果】
------------------------------------------------
- IDE 语法检查通过（无诊断错误）
- 页面加载无 JS 报错（仅 Google Fonts 网络拦截，
  不影响功能，字体回退系统字体）

 【2026-08-17】新增「学习论坛」（forum/ 目录）
════════════════════════════════════════════════════════

【本次更新内容】

一、全新学习论坛页面（零第三方依赖）
------------------------------------------------
1. 新增 forum/ 目录三个文件：
   - forum/index.html  页面骨架（语义化标签 + 跳转主内容链接）
   - forum/forum.css   设计系统（延续电感蓝紫 + 明暗双主题）
   - forum/forum.js    数据层 + 渲染 + hash 路由 + 交互
2. 设计参考：Stack Overflow（统计列/标签/徽章激励）、
   掘金（信息流卡片/暗色模式）、V2EX（极简节点分类）、
   力扣每日打卡、freeCodeCamp 进度激励
3. search.html 侧栏新增「学习论坛」入口

二、四大核心技能模块
------------------------------------------------
1. 前端开发 / 算法与数据结构 / 后端与数据库 / AI 与机器学习
2. 每个模块包含四个页签：
   - 技能介绍：知识图谱（点击知识点即搜索相关讨论）
   - 学习资源：官方文档/经典书籍/视频课程/社区资源卡片
   - 相关讨论：该模块帖子列表（可直接发帖）
   - 我的进度：学习状态 + 进度滑杆 + 学习历程时间线

三、完整论坛功能
------------------------------------------------
1. 用户系统：注册/登录/退出（含 4 个内置演示账号）
2. 帖子管理：发布（Markdown + 模块 + 标签）/ 编辑 / 删除
3. 评论与回复：支持 @某人 回复引用
4. 分类标签：模块分类 + 帖子标签 + 热门标签云
5. 搜索：顶栏全局搜索（标题/正文/标签），快捷键 /
6. 热门话题：右侧栏实时 Top5

四、用户互动系统
------------------------------------------------
1. 点赞：帖子、评论均可点赞（实时计数 + 通知对方）
2. 收藏：收藏帖子，侧栏「我的收藏」统一查看
3. 关注：关注用户，主页展示关注者数，推荐关注列表
4. 私信：会话列表 + 聊天窗口 + 未读提示
5. 通知：点赞/评论/关注/私信/系统 5 类通知，
   顶栏未读角标 + 通知中心 + 一键全部已读

五、学习进度追踪
------------------------------------------------
1. 每日打卡：侧栏打卡卡，连续打卡天数统计
2. 模块进度：未开始/学习中/已掌握 三态 + 0-100% 滑杆
3. 学习历程：按日期记录学习内容（时间线展示）
4. 成就徽章：初入论坛/小有所成/点赞收割机/持之以恒/
   满级学霸/社交达人 共 6 枚，动态解锁
5. 个人主页：发帖/获赞/关注者/连续打卡/总进度统计 +
   徽章墙 + 学习历程 + TA 的帖子

六、体验与无障碍
------------------------------------------------
1. 明暗主题一键切换（记忆选择）
2. 桌面三栏布局（导航 + 信息流 + 热门推荐）
3. 键盘可达（焦点环、/ 聚焦搜索、ESC 关闭弹层）
4. 尊重系统「减少动态效果」设置
5. 论坛数据存浏览器 localStorage，清缓存可重置

════════════════════════════════════════════════════════

【本次更新内容】

一、全站设计系统统一（Design Tokens）
------------------------------------------------
1. 主色升级：模板蓝 #4a8eff → 电感蓝紫 --primary #4F6BF0
   - 新增语义色变量：--cyan 辅助青、--accent 成就琥珀、
     --success/--danger 判题语义色、--primary-soft 选中浅底
2. 三个页面（search/watch/skill）:root 变量统一，页面底色、
   文字、边框全部变量化
3. 批量替换旧蓝系硬编码 249 处（含 rgba 变体），残留 0

二、去除「AI 塑料感」（渐变收敛）
------------------------------------------------
1. 普通按钮（搜索提交/快捷弹窗/抽屉/聊天发送等）
   由 135° 渐变改为纯色，hover 时加深
2. 渐变仅保留品牌场景：logo 徽标、AI 悬浮球、角色头像、
   进度条；卡片阴影去掉蓝色辉光，改中性阴影

三、watch.html 深色观影模式
------------------------------------------------
1. 播放器海报底改为深色沉浸渐变；字幕条深色白字
2. 播放进度条改品牌渐变（蓝 → 青）
3. 字幕切换新增 150ms 淡入淡出过渡（不再跳变）
4. 顶栏毛玻璃升级 blur(12px) saturate(180%)

四、动效升级（克制、有目的）
------------------------------------------------
1. 全站按钮新增按压反馈 :active scale(.97)
2. 错题本/学情诊断弹层入场 scale(.96)+淡入动画，遮罩压暗
3. 新增 prefers-reduced-motion 全局降级
   （系统开启「减少动态效果」时动画退化为瞬时）
4. skill 页：移除全屏扫描线动画；logo 扫光改为悬停触发；
   粒子分层配色与新品牌色统一

五、细节优化
------------------------------------------------
1. 错题卡新增琥珀色「未复习」标记，复习通过统一成功绿
2. 搜索首页/播放页侧栏、chip、表单 focus 状态统一新色系
